# 站內確認視窗

系統操作的確認一律使用 shared UI kit 的 `ConfirmDialog`，不呼叫瀏覽器原生的
`confirm`、`alert` 或 `prompt`。視窗沿用既有 Modal 主題、手機排版及中英按鈕。
確認前不送出寫入，取消、關閉與 Escape 不執行動作。送出期間禁止重複確認與關閉，
失敗訊息保留於視窗內，成功後關閉並更新畫面。

適用品牌及廠商刪除／停用、商品及照片刪除、詢價刪除及套用最新匯率。成交確認
已使用站內 FormDialog，維持完整金額預覽。

## 驗收條件

| 條件 | 測試名稱／檢查 |
|---|---|
| 取消不執行，只有確認才執行 | `取消與關閉不執行操作，只有明確確認才執行` |
| 送出中不重複確認，也不可關閉 | `處理中禁止重複確認與關閉` |
| 共用取消與處理中文字依語系顯示 | `確認視窗的按鈕支援英文` |
| 原生確認不再出現 | ESLint `no-restricted-globals`、`no-restricted-properties` |
| 每個操作接線正確，錯誤留於視窗 | 各畫面瀏覽器人工驗收，UI 組裝不補執行期測試 |

測試先於新增共用元件建立，之後鎖定；不修改既有測試條件。

## 驗證紀錄（2026-10-20）

- 新元件尚未實作時，三項測試因元件未匯出失敗；實作後三項全數通過。
- 全站五處原生確認呼叫已移除；ESLint 禁止全域及 window／globalThis 的原生視窗呼叫。
- 瀏覽器確認品牌、廠商、商品、照片的刪除／停用都開啟站內視窗，取消後保留資料；
  套用最新匯率使用同一共用視窗。英文 320px 與中文 390px 的視窗按鈕及文案均可讀。
- `make check` 與 shared 獨立驗證通過，新增共用元件與測試可整包移植。
