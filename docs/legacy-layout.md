# 舊版介面對齊驗收

參考來源：`pre-owned-luxury-old/frontend/src/app` 與 `frontend/src/components/ui-*.module.css`。

| 驗收條件 | 測試名稱 | 驗證方式 |
| --- | --- | --- |
| 商品列表在桌面呈現縮圖、名稱與 SKU、品牌、年份、建檔日期及金額；手機切換精簡卡片，保留篩選、分頁和詳情入口。 | 商品列表桌面表格與手機卡片 | 瀏覽器檢查桌面／手機與現有測試 |
| 商品詳情照片與資料分欄，窄螢幕改直向；編輯和新增表單採雙欄，手機單欄。 | 商品詳情與表單響應式排版 | 瀏覽器檢查桌面／手機 |
| 登入及註冊沿用舊版置中品牌卡片與奶油色背景，維持雙語和驗證。 | 登入註冊品牌卡片 | 瀏覽器檢查及既有 auth／registration 測試 |
| 頁首、導覽與共用表格對齊舊版間距，現有權限、操作和模組邊界不變。 | 既有功能與架構維持有效 | make check |

舊版沒有對應頁面的註冊碼設定等保留現有功能；不新增未實作的結算、AI 助手等功能。
純 UI 組裝依開發指南不新增執行期測試；實作期間不修改既有測試檔。

## 視覺驗收紀錄

- 使用獨立 Next.js 預覽與合成資料, 不連接真實資料庫。
- 桌面 1280px、平板 820px、手機 390px: 商品列表表格／卡片、長名稱、空清單與分頁通過。
- 商品詳情照片／資料分欄、照片操作及新增商品雙欄／單欄表單通過。
- 品牌與廠商手機卡片、登入／註冊品牌卡片、設定頁頁首與底部導覽通過。
- 檢查中英文文案; 手機與平板的頁面沒有橫向溢出。較窄的桌面表格可在卡片內橫向捲動。
- 保留目前的彈出視窗編輯流程與詢價／成交功能; 不新增舊版專屬功能。
- 舊專案 CSS 引用的 `marble-cream.png` 並不存在於舊專案, 登入背景沿用奶油色漸層。
