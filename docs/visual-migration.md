# 第一步：視覺主題與應用外殼

沿用舊專案的小花標誌、奶油白背景、香檳金點綴、墨棕文字與襯線標題，以新版設計變數、
UI kit 與模組邊界實作。此階段只提供既有頁面的入口。

## 驗收條件

| 條件 | 測試名稱 | 驗證方式 |
|---|---|---|
| 一般操作區始終有首頁入口，其他入口遵循模組啟用與權限 | 一般操作區包含首頁與可見模組，管理區沿用權限篩選 | Vitest |
| 首頁不會在其他頁面被標成目前頁面；子頁正確標記所屬功能 | 首頁只在根路徑啟用、子頁沿用所屬導覽且不誤判相似前綴 | Vitest |
| 淺色主題的正文、次要文字、按鈕及狀態訊息保持可讀 | 主題文字與對應背景的對比至少為 4.5 | Vitest |
| 安裝啟動畫面與頁面底色一致，原生控制項使用淺色 | manifest 與淺色主題背景一致 | Vitest |
| 登入頁保留標誌、執行期系統名稱、裝飾分隔、帳密欄位及錯誤訊息 | 登入頁在桌面與手機可讀且可操作 | 瀏覽器人工驗收 |
| 桌面顯示完整側欄，平板顯示圖示窄欄，手機顯示品牌列與底部導覽 | 三種寬度的外殼與內容均無橫向溢出 | 瀏覽器人工驗收 |
| 帳號選單可進入設定、切換有權限的區域及登出 | 桌面與手機帳號選單可操作 | 瀏覽器人工驗收、既有 account-menu 測試 |
| 所有新增文案有中英兩份，主題也套用到表單、列表與對話框 | 中英文代表頁面與共用元件套用主題 | 瀏覽器人工驗收、make check |

UI 組裝與 CSS 使用瀏覽器驗收，不為畫面組裝補執行期測試。自動測試先於實作建立，實作期間鎖定。
