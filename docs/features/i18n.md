# 語系

前後端同一個語系：語系存在 `locale` cookie，每個 API 請求都帶 `Accept-Language`，
後端的錯誤訊息跟著 UI 走。字串放哪裡、怎麼加語言見 [`extending/i18n.md`](../extending/i18n.md)。

## 程式與測試

- 前端讀寫語系：[`shared/i18n/locale.server.ts`](../../apps/web/shared/i18n/locale.server.ts)、
  [`shared/api/headers.ts`](../../apps/web/shared/api/headers.ts)
- 後端依語系選錯誤訊息：[`shared/http/errors.py`](../../apps/api/shared/http/errors.py)、
  [`test_errors.py`](../../apps/api/tests/shared/http/test_errors.py)
- 英文完整流程、語系切換及前後端錯誤：[`english-acceptance.spec.ts`](../../e2e/tests/english-acceptance.spec.ts)
- iPhone Safari 英文操作：[實機驗收](../acceptance/iphone-safari.md)
