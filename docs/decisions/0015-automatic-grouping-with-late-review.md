# 0015. 依 LINE 原始時間自動分組，收集結束後的遲到訊息交由人員加入

狀態：採用（2026-11-02）

取代：[0014](0014-manual-collection-finalization.md)

## 背景

[0014](0014-manual-collection-finalization.md) 為了避免延遲與亂序訊息改動商品，把分組交給人員確認定稿。
實際使用後，每組都要人工確認的負擔比偶發的遲到訊息更大；而收件本身已保存 LINE 的原始時間，
圖片下載與加工也已和分組拆開，延遲只會讓內容晚到，不會改變它的時間。

## 決定

群組啟用後持續收件，依原始時間沿用原本的規則自動分組：第一張圖開始一件商品，
收過文字後再來圖片就結束前一件、開始下一件。最後一件由人員在暫存列表按「收集完成」結束。
每件商品記下收集區間（第一張圖到下一件的第一張圖），區間不隨商品建檔或放棄刪除。

收集結束後才送達的訊息，依原始時間找出所屬區間，放進那件暫存並標為待加入，
由人員加入或忽略；分不出先後的同毫秒圖文也一樣。商品已建檔、放棄或沒有區間時略過。
建檔只要求收集結束、原圖齊全且沒有待加入；圖片加工在原圖保存後即開始，不擋建檔。
AI 預填仍只在收集結束時讀取當時的原文跑一次，結果不明時不重送。

## 後果

分組不需要人工步驟，畫面回到原本的列表與詳情。遲到內容不會自動改動已結束的商品，
但人員要留意待加入提示；落在已建檔商品區間的遲到訊息不再保留。
收集中商品裡先送達、原始時間較晚的文字，會在較早的圖片送達時一起移到新商品。
若之後發現遲到訊息常常需要另開商品，或 LINE 提供可靠的商品識別，再重新檢討區間規則。
