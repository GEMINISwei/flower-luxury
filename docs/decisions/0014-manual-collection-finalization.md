# 0014. 收件先保存，由人工完成收集與分組定稿後才加工

狀態：被 [0015](0015-automatic-grouping-with-late-review.md) 取代（2026-11-02）

## 背景

LINE 重送可能延遲或亂序，等待固定三分鐘不能證明商品分組完整。原圖卻需要盡快下載保存。
指令批次還會讓現場人員負擔開始與結束操作，且遲到訊息若自動改組，可能改動已人工整理的商品。

## 決定

啟用群組後持續持久保存收件，下載佇列立即保存原圖，不解碼。人員以輪次 ID 完成收集，
固定目前範圍並提出分組，新訊息進下一輪。歧義與時間屬於已完成範圍的遲到內容交給人員，
可加入同來源未定稿組別、另建或忽略，不自動重切。

人工確認分組後固定原文與原圖鍵快照，同一交易才排入圖片加工與一次 AI 預填。
成功工作不重跑；圖片可對同一快照重試失敗項目。AI 呼叫前獨立提交結果不明狀態，
中斷後由人工整理，不重送可能已成功的外部請求。工作 payload 只有識別與版本。

## 後果

保存原圖不必等待分組，人工欄位與已完成成果有明確邊界。代價是每組需要一次人工定稿，
無法自動判斷的內容需要操作人員處理。系統重啟保留輪次，不以靜默或群組停用推斷完成。
若日後來源提供可靠的商品識別與結束事件，可以重新評估自動定稿；不能只靠延長緩衝時間。
